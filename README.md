# LINUX SB 我的活跃度

油猴脚本：在 `https://linux.sb/*` 的右下角增加可收起的面板，读取当前登录账号的官方活跃度页面，并显示提升建议。

## 安装

1. 安装浏览器扩展 Tampermonkey（油猴）。
2. 在油猴菜单中选择“添加新脚本”。
3. 打开 `linuxsb-activity.user.js`，复制**全部内容**覆盖编辑器中的默认代码，保存。
4. 登录 <https://linux.sb/> 并刷新网页；右下角出现“我的活跃度”面板。

## 使用

- 面板顶部用大号数字显示官方活跃度分数，旁边突出账号状态（例如“39 分 · 观察期”）。收起后的按钮也保留分数与状态。
- 其余未满分项默认展示在“其他可提升”；没有偏低项时，所有未满分项展示在“还可提升”。
- 每项评分仅显示 `当前得分/上限`，例如 `3/10`。红包项目使用官方名称“参与红包”。项目条件、统计周期和具体计分以 [官方明细](https://linux.sb/community_activity/) 为准。
- 只有满分项收进“已满分”，默认折叠；展开后与“优先提升”使用相同的项目标题、得分、进度条和指南说明样式。总分独立读取，不用已识别项目的分数之和替代。
- 点击“刷新”重新读取；网站自身的数据更新或缓存可能存在延迟。
- 每项具体说明从官方“活跃度提升指南”读取，默认隐藏；鼠标悬停该项时显示，移开后隐藏。触屏点击该项切换说明，键盘聚焦后按 Enter 或空格切换，按 Escape 收起。已满分项也使用相同交互。
- 点击“收起”缩为按钮，展开状态保存在当前浏览器中。无论面板是否收起，每次打开页面都会自动读取活跃度并更新按钮上的分数和状态；展开面板直接显示已获取的数据，无需再次请求。
- 未登录、网络超时、验证页面或结构不匹配时显示明确提示，不显示旧账号数据。

## 提升说明的来源

每次刷新时，直接从 [官方活跃度页面](https://linux.sb/community_activity/) 的“活跃度提升指南”按项目名称读取说明，不保存写死的建议。支持有效参与天数、有效主题、参与主题、参与版块、参与红包、签到天数、主动打赏、被动打赏、精华/热议、注册时长。

指南中的数字示例不会作为账号得分。如果某个项目的说明无法识别，明确提示查看官方明细，不自行生成计分规则。统计周期、上限、条件和扣分始终以官方页面为准。

## 实现和验证范围

脚本只请求本站的 `/community_activity/`，使用浏览器已有的登录状态。只解析返回的文字，分数、状态和项目名称通过 `textContent` 显示，不运行返回的脚本或加载图片，不自动发帖、回帖、签到或领取奖励。没有第三方依赖，不保存分数或登录凭证。
